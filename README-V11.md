# Walid Voyages V11 - Homepage fidèle au visuel choisi

Cette version remplace la couverture V10 par une composition fidèle à la référence : visuel voyage à gauche, bleu nuit et violet à droite, logo sans cartouche blanc, grands titres, liens officiels Vols / Hôtels, éléments et boutons réels et accessibles.

- Fichiers à la racine : publier sur GitHub Pages, main / root.
- `index.html` / `ar.html` : deux accueils FR/AR.
- `voyage-cinematic-left.jpg` : partie visuelle du visuel de référence, sans éléments d'interface.
- `logo-walid-transparent.png` : copie du logo en transparence pour l'en-tête. Original JPG conservé sans modification.
- Admin / Firebase : fichiers inchangés. Testez la connexion et l'enregistrement avant production.
- Cloudinary Signed Upload ne peut pas fonctionner directement sans backend sécurisé. L'administration accepte les URL d'images Cloudinary.
- Les boutons Vols et Hôtels ouvrent les URL officielles, sans prétendre transmettre automatiquement des critères de recherche.
- Les ajustements SEO des pages statiques ne sont pas automatiquement publiés par Firebase.
- Éviter tout engagement de classement Google garanti.
