WALID VOYAGES — SITE CINEMATIC FR + AR

1. Décompressez le ZIP. Déposez TOUS les fichiers dans la racine de votre dépôt GitHub.
2. GitHub Settings > Pages > Deploy from branch > main / (root). Désactivez les anciens workflows Astro.
3. Testez index.html, ar.html, admin.html, les cartes électroniques, et les liens vols/hôtels.
4. Les images incluses sont hero-cinematic.webp et omra-feature.webp.
5. Les textes HTML sur la couverture restent indexables et les boutons restent cliquables.
6. Admin Firebase conserve les fonctions antérieures. Les réglages de bannière Firebase existants ne remplacent pas automatiquement le nouveau fond sans adaptation supplémentaire.
7. L'upload Cloudinary Signed depuis le PC nécessite un backend sécurisé; la clé API seule ne suffit pas.
8. Le SEO dynamique des nouveaux articles nécessite une génération de pages HTML statiques après publication.
9. Ne pas revendiquer le rang n°1 sur Google sans preuve. Vérifiez les avis Google par agence.
10. Le site officiel vols: https://www.walid-voyages.com/vols ; hôtels: https://www.walid-voyages.com/liste
